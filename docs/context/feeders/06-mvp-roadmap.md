# Wheeln — MVP vs Later Phases

## Day-1 launch (MVP) — 17 items
1. Email + Google/Apple auth
2. Profile creation/editing
3. Admin-curated location database (seed 50+ locations)
4. Location browse: list + map, type/state filters
5. Location detail: ratings, gallery, check-in history
6. Create check-in: photo, message, stars, difficulty
7. Social feed with community/friends toggle
8. Likes and comments
9. Friend requests
10. Badge system (all standard badges + evaluation logic)
11. Rankings: top-rated, most challenging, most popular
12. AdMob banner + interstitial ads
13. $1/month ad-free subscription (RevenueCat)
14. Push notifications: likes, comments, badges, friend requests
15. User location submission with admin approval
16. Admin dashboard: location approval, moderation, user management
17. QR deep-link handling for event check-ins

## Phase 2 (~60-90 days post launch)
Organizer web portal + Stripe checkout; AI recommendations (ship after ~500 active users); Printful fulfillment; Resend QR/badge emails; Elite animated badges + featured placement; reporting system; personal leaderboard rank; private profiles; username-change cooldown UI.

## Phase 3 (community expansion)
Overlanding/SxS; motorcycle track days; gravel/adventure; rock crawling with difficulty metadata; car shows and Cars & Coffee; drag-and-drive; karting with lap times; vehicle garage; GPS route recording; group check-ins.

## Founder guidance given
Keep MVP to the 17 items; plan 3-5 months with a solid freelancer; add a 20-30% budget cushion; seed 50-100 quality locations before launch.
